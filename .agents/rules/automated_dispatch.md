# Automated Outreach Dispatch Rule

## Core Directive
Whenever newly discovered jobs or target referral contacts are identified, immediately and automatically proceed to dispatch the connection invites or direct LinkedIn messages via browser automation. 

**DO NOT PAUSE TO ASK FOR CONFIRMATION.**
- Do not ask "Would you like me to trigger the automated dispatch...?"
- Execute the outreach workflow end-to-end automatically.
- Check 1st-degree vs 2nd-degree connection status.
- Send personalized 1st-degree direct messages or customized connection notes with the exact Job ID and portfolio link (`https://kausal.in`).
- Update `applications_tracker.json` and report the dispatch log with full transparency.
